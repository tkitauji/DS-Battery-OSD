# Microsoft Store掲載文（日本語）

## 製品名

DS Battery OSD

## 短い説明

DualSenseのバッテリー残量を、ゲーム中も見やすいシンプルなOSDで表示します。

## 説明

DS Battery OSDは、Windowsに接続したDualSense / DualSense Edgeのバッテリー残量を画面上に表示する軽量ツールです。

- USB / Bluetooth接続を自動検出
- バッテリー残量、充電中、充電完了（FULL）を表示
- 20%未満になると赤色で警告
- 背景のないシンプルな常時最前面表示
- ドラッグで好きな位置へ移動し、次回起動時も位置を復元
- コントローラー切断中は自動的に非表示
- 初回起動後、Windowsへのサインイン時に自動起動（Windows設定から無効化可能）

DualSenseが満充電ステータスを通知している間は「FULL」と表示します。ケーブルを抜くと、コントローラーから通知される段階的な残量値に切り替わるため、直後に80%などと表示される場合があります。実際の充電量が瞬時に減ったわけではなく、DualSenseの残量通知仕様によるものです。

ウィンドウモードおよびボーダーレスフルスクリーンで使用できます。排他的フルスクリーンには対応していません。

本アプリは個人情報を収集・保存・送信せず、接続された対応コントローラーのHID情報だけを端末内で読み取ります。

## 検索語候補

DualSense, バッテリー, コントローラー, OSD, PlayStation, ゲーム

## restricted capabilityの説明

`runFullTrust`は、デスクトップ上に常時最前面のWPFオーバーレイを表示し、Windows HID APIを通じてローカル接続されたDualSense / DualSense Edgeのバッテリー状態を読み取るために必要です。アプリは外部通信を行わず、個人情報を収集・保存・送信しません。
